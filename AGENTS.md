# AGENTS.md - BrowsePilot AI

Build BrowsePilot AI as a TypeScript monorepo containing a web app, Chrome Extension Manifest V3 side panel, and shared agent package.

## Working Rules

- Keep implementation phase-based.
- Do not skip the web app, extension, shared package, or safety model.
- Use mock AI mode by default.
- Never hardcode API keys.
- Keep the project runnable without `GEMINI_API_KEY`.
- Run available typecheck, lint, and build scripts after meaningful edits.

## Visual Direction

- Light gray experimental product launch style.
- Huge black uppercase typography.
- Monochrome futuristic editorial layout.
- Thin technical line decorations.
- White rectangular CTA buttons.
- Precise spacing.

Avoid purple, orange, blue gradients, generic chatbot UI, robot mascots, random blobs, and cluttered dashboard layouts.
